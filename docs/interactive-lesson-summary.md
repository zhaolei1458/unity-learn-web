## 技术亮点

1. **动态 Three.js 加载**：避免首屏加载过慢
2. **阶段隔离**：每个阶段独立场景，互不干扰
3. **清理机制**：防止内存泄漏
4. **HTML 标签叠加**：3D 场景 + 2D 文字说明
5. **错误反馈**：点击错误时红色闪烁
